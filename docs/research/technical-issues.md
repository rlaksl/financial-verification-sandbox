# 기술 쟁점 대장

기준일: 2026-11-26

## 문서의 역할과 표기

해결할 기술 문제를 관리한다. 결정 상태는 [결정·상태 대장](../decision-register.md), 방어 범위는 [위협 모델](../security/threat-model.md), 근거 원문은 [명세·소스 분석 기록](spec-source-analysis.md)에 있다.

| 축 | 값 |
| --- | --- |
| 해결 방향 | 미정 / 방향 확정 (무엇을 해야 하는지는 정해짐) / 우선 후보 / 비교 중 / 연구 |
| 구현·검증 | **현재 구현·실행 검증을 완료한 쟁점은 없다.** 모든 쟁점이 미구현·미검증이다 |
| 시점 | 관문(G1-a ~ G7), TF(토큰 형식 분리 실험), P2(Phase 2 실험), DD(상세 설계), v0.x |

T-01 ~ T-29는 최초 식별자 그대로다. T-30 ~ T-42는 새로운 주제가 아니라, 기존 결정과 논의에 있었으나 쟁점 식별자가 없던 항목에 추적용으로 부여한 것이다.

근거 표기: [명] 명세 확인, [소] 소스 확인, [판] 판단, [미] 미확인. 식별자(SPEC, SRC)는 명세·소스 분석 기록을 가리킨다.

## I. OAuth2 외 기술 심화 연구 (H-05)

OAuth2 계열 선택과 무관하게 추적한다. 모두 구현하는 것이 아니라 같은 요구사항과 조건으로 비교해 선정한다.
