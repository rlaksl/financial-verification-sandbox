## 표기 기준

| 축 | 값 |
| --- | --- |
| 상태 | 확정 / 우선 후보 / 검토 중 / 미결정 / 제외 / 대체됨 |
| 근거 | 판단 / 명세 확인 / 소스 확인 / 실행 검증 |
| 검증 | 미검증 / 검증 예정 / 검증 통과 / 검증 실패 / 검증 불충분 / 해당 없음 |

- **요구사항·기술 쟁점·PoC 항목 중 실행 검증을 완료한 항목은 없다.** 프레임워크 관련 근거는 모두 소스 읽기이며 실제 동작은 PoC에서 검증한다.
- 개발 도구는 D-O24만 범위를 한정해 실행 검증했다 (macOS arm64, 검증 불충분). 개발 도구의 검증 상태는 애플리케이션·PoC의 검증 상태와 구분해 기록한다.
- 명세나 소스를 확인한 것을 실행 검증으로 기록하지 않는다.
- 버전이 바뀌면 관련 검증은 다시 수행한다.

## 식별자 원칙 (D-O22)

식별자는 변경하거나 재사용하지 않는다. 새 항목에는 새 식별자를 부여한다. 제외되거나 대체된 항목도 이력을 유지하고, 대체된 경우 후속 식별자를 연결한다.
