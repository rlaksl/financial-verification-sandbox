# financial-verification-sandbox
A security-focused B2B financial verification sandbox for simulated account holder verification and micro-deposit verification.

외부 고객사 서버에 모의 계좌 인증 API를 제공하는 독립 B2B 플랫폼입니다. 고객사 연동 과정에서 발생하는 보안과 데이터 정합성 문제를 다루는 것을 목표로 합니다.

## 고지 사항

- 실제 금융기관이나 통신사와 연결하지 않습니다.
- 인증 결과는 실제 계좌 소유나 법적 본인확인을 의미하지 않습니다.
- 모든 테스트 데이터는 가상 정보입니다.

## 현재 상태

Phase 0(초기 설정과 설계 문서 정리) 진행 중이며, 아직 애플리케이션 코드는 없습니다.
현재 단계와 다음 작업은 [docs/status.md](docs/status.md)에서 확인할 수 있습니다.
